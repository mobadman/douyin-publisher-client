# 短视频批量发布助手 3.0.5

Windows 本地批量发布客户端。通过应用专用 Chrome Profile 读取飞书表格和登录发布平台，使用本地封面、文案、Tag 与商品配置生成计划，人工复核后执行定时发布。

当前支持：

- 抖音主页号
- 抖音商城号（默认挂车，现场查询商品链接）
- 微信视频号
- 多工作区、多账号及独立本地素材库
- 1–44 条视频排期、中断续发和发布 ID 同步
- 飞书【AI标识】与抖音“内容由AI生成”自主声明
- TXT、CSV 发布 ID 记录，以及按飞书实际行排序的纯 ID 单列复制

生产里程碑为 3.0.2；3.0.3 增强 Windows 文件选择窗口兼容性；3.0.4–3.0.5 新增 AI 声明与 ID 表格能力。历史安装包和对应源码快照见 [Releases](https://github.com/mobadman/douyin-publisher-client/releases)。

## 安全边界

飞书与在线素材只读；账号登录资料、下载缓存和发布日志只保存在用户本机，不进入仓库。任意网页结构、账号、素材或网络异常会停止当前任务并保留已完成进度。
