# 短视频批量发布助手 3.0.6

Windows 本地批量发布客户端。通过应用专用 Chrome Profile 读取飞书表格和登录发布平台，使用本地封面、文案、Tag 与商品配置生成计划，人工复核后执行定时发布。

当前支持：

- 抖音主页号
- 抖音商城号（默认挂车，现场查询商品链接）
- 微信视频号
- 多工作区、多账号及独立本地素材库
- 1–44 条视频排期、中断续发和发布 ID 同步
- 飞书【AI标识】与抖音“内容由AI生成”自主声明
- TXT、CSV 发布 ID 记录，以及按飞书实际行排序的纯 ID 单列复制

生产里程碑为 3.0.2；3.0.3 增强 Windows 文件选择窗口兼容性；3.0.4–3.0.5 新增 AI 声明与 ID 表格能力；3.0.6 修复平台已经明确返回发布成功后，作品管理即时记录尚未出现而导致批次中断的问题。历史安装包和对应源码快照见 [Releases](https://github.com/mobadman/douyin-publisher-client/releases)。

## 3.0.6 发布确认规则

程序只在抖音明确显示“发布成功”“提交成功”“作品发布成功”或“已提交审核”后，将当前视频标记为平台已确认提交并继续下一条。页面仅跳转、等待超时或出现失败提示都不会被当作发布成功，也不会自动重复点击发布。

作品管理不再承担发布后的即时硬核验。批次完成后，使用软件现有的“同步视频ID”功能从抖音个人主页核对作品并生成ID记录。

## 安全边界

飞书与在线素材只读；账号登录资料、下载缓存和发布日志只保存在用户本机，不进入仓库。任意网页结构、账号、素材或网络异常会停止当前任务并保留已完成进度。发布按钮每条视频只点击一次，结果不明确时禁止自动重试。

## 本地验证

```powershell
npm install
npm test
npm run test:ui
npm run dist
```

真实发布链路应先使用可删除的定时视频和测试账号验证。3.0.6 首次生产使用建议至少勾选两条测试视频，确认每条收到平台成功提示后能够直接进入下一条，再执行视频ID同步。
