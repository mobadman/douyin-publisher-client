# 抖音批量发布助手 1.1.0

这是一个 Windows 本地客户端，用脚本完成“从飞书读取当天视频 → 下载附件 → 本地匹配内容资产 → 生成排期 → 人工复核 → 抖音创作者中心逐条定时发布”的重复工作。正式流程不使用生成式 AI，不读取用户日常 Chrome 个人资料，也不需要飞书开放平台 App ID。

## 工作原理

客户端为飞书、测试账号和发布账号分别维护应用专用的 Chrome 资料目录。飞书阶段通过页面的表格复制与附件下载能力只读获取数据，不包含任何飞书写入逻辑。素材按【产品型号】匹配本机维护的封面、文案和 Tag。发布阶段使用已登录的抖音创作者中心，按人工确认的计划逐条上传、填写并定时发布。

任意一条发生错误，整批立即停止且不重试后续视频。错误报告和页面截图使用中文说明，保存在本地发布日志中，只允许人工接管。

1.0.1 增加启动隔离保护：当前计划缓存即使被人工编辑损坏，也只会禁用该计划，不再影响账号管理、登录资料、设置和其他界面加载。

1.0.3 撤销未通过实际流程验证的文件窗口改造，恢复1.0.1的封面选择实现，并临时完全停用全屏覆盖层。自动流程期间必须由人工保证不操作设备。

1.0.4 进一步修正回退基线：封面文件选择辅助程序恢复为0.6.6实测成功的确切二进制。正式打包前强制校验其 SHA-256，禁止被源码重新编译版本覆盖。全屏覆盖层仍完全停用。

1.0.5 根据竖封面现场截图做定点修复：保留0.6.6已经能正确打开窗口的 Chrome 鼠标点击，只替换窗口打开后的文件名输入方式。程序直接定位标准“打开”对话框中的文件名输入框，写入完整图片路径并调用“打开”，不再依赖中文系统下不稳定的 Alt+N 快捷键。覆盖层仍完全停用。

1.1.0 完成正式版界面整理，统一产品名称为“抖音批量发布助手”，加入账号管理、实验功能提示、打赏入口和新版应用图标。发布与飞书拉取核心流程沿用1.0.9实测版本。

## 首次使用前的准备

飞书电子表格必须包含以下表头：

- 【素材链接】：飞书附件或可下载的 HTTPS 链接。
- 【产品类目】：用于排序，尽量避免连续发布相同品类。
- 【产品型号】：用于匹配封面、文案和 Tag。
- 【发布时间】：运营人工填写希望发布的日期。
- 【允许发布】：可选。存在时，只有明确肯定值的行会进入计划。

本地素材库在首次启动时自动创建：

```text
本地素材库/
  封面库/产品型号/*.jpg
  文案库/产品型号.txt
  Tag库/产品型号.txt
  下载缓存/
  发布日志/
```

文案和 Tag 文件每行代表一个可复用方案，以 `//` 开头的行忽略。Tag 用逗号分隔，不必写井号，最多五个。正文只统计汉字且不超过20个。产品型号文件名必须和飞书单元格一致。

## 操作步骤

1. 首次打开软件会进入“新手指引”，按照清单准备飞书表格和本地素材库。
2. 在主工作台保存飞书表格链接，打开飞书专用 Chrome 登录，并点击“检测登录”。
3. 打开“发布账号”的专用 Chrome，首次扫码登录后返回客户端检测账号并人工核对。
4. 选择发布日期，点击“拉取飞书并生成计划”。
5. 逐行检查视频文件、品类、产品型号、发布时间、文案、Tag、封面和状态。
6. 全部就绪后勾选人工授权，点击“开始批量发布”。
7. 明确的完成提示出现后，到抖音作品管理核对发布数量与定时时间。
8. 确认无误后可一键清空下载缓存，发布日志会保留。

独立小号验证放在“测试工具”页面，正式工作台只显示发布账号和批量流程。

## 防误操

1.0.3 临时完全停用全屏水印和输入拦截，因为覆盖层会干扰抖音封面的 Windows 文件选择窗口。拉取飞书和发布视频期间，使用者必须停止操作鼠标、键盘，不要切换窗口或运行其他前台任务。遇到问题时等待当前步骤报错停止，再由人工接管并检查页面。

## 耗时估算

首次拉取按“固定准备约1分钟 + 每条约36秒”估算，8至20条显示约6至13分钟，与实测20条约13分钟对应。发布首次按每条约150秒估算，并参考当前计划的视频总大小。每次成功完成后，客户端只在本机记录任务类型、条数、视频总大小和实际耗时，使用最近12次记录的中位数重新校准；中位数可以降低网络异常等单次极端值的影响。失败或人工接管的任务不参与估算。

## 排期与发布规则

- 8至14条从10:00开始按1小时一条。
- 15至20条先按1小时、后按半小时，最后一条不晚于23:00。
- 排序优先避免连续相同品类；只剩相同品类时优先避免连续相同型号。
- 发布前等待页面右上角、右下角的上传或处理状态消失，并要求发布按钮连续2秒可用。
- 最终发布按钮只点击一次，绝不自动重试。
- 正式批量发布只允许使用“发布账号”；测试账号只能在测试工具中使用。

## 安全边界

- 不读取 `%LOCALAPPDATA%\Google\Chrome\User Data`，所有登录状态保存在应用自己的资料目录。
- 不写入、覆盖或删除飞书表格和在线素材。
- 清理功能只删除客户端下载缓存和当前计划，不删除本地内容资产与发布日志。
- 网页结构、账号状态、素材、网络或规则出现不确定性时停止，不猜测、不绕过。
- 多人团队首次使用时，每台电脑分别扫码登录各自有权限的飞书和抖音账号。

## 开发与验证

```powershell
pnpm start
pnpm test
pnpm run dist
```

构建安装包时会编译 Windows 原生文件选择辅助程序。当前自动测试覆盖配置迁移、中文错误、账号识别、飞书数据解析和附件定位、素材库、排期、发布结果、输入校验与耗时统计。真实网页结构仍应在平台更新后通过测试小号重新验证。
