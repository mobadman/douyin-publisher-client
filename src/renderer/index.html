软件如何工作

短视频批量发布助手以“发布工作区”隔离不同平台和账号。每个工作区分别保存飞书、发布账号、表格链接和本地素材库。软件从对应飞书表格复制只读数据，逐个下载当天附件，再按产品型号匹配封面、文案和 Tag；商城号还会匹配商品短标题与已确认的商品链接。整个流程不使用生成式 AI，也不写入飞书。

飞书表格需要准备什么

必需列

【素材链接】【产品类目】【产品型号】【发布时间】。表头文字需与设置一致。

可选列

【允许发布】存在时，只有填写“是、允许、可发布、发布、true、1、yes、√”的行会进入计划。

素材链接

使用飞书附件或可下载的 HTTPS 链接；登录账号必须拥有表格查看和附件下载权限。

发布时间

人工填写希望发布的日期。软件只拉取所选日期，具体时刻按排期规则自动生成。

本地素材库结构

本地素材库/
  封面库/产品型号/*.jpg
  文案库/产品型号.txt
  Tag库/产品型号.txt
  商品短标题库/产品型号.txt（仅商城号必需）
  商品配置/产品型号映射.csv（仅商城号必需）
  下载缓存/
  发布日志/

文案和 Tag 文件每行一个方案；Tag 用逗号分隔，不必写 #。产品型号必须与飞书单元格一致。

日常操作步骤

  1. 先选择发布工作区；平台、账号、飞书表格和素材库会随工作区一起切换。
  2. 保存当前工作区的飞书表格链接，打开专用 Chrome 登录飞书并检测。
  3. 打开当前发布账号，首次扫码后检测并人工核对。商城号在本地型号映射表中维护真正的抖店搜索型号。
  4. 生成商城计划后点击“现场获取本批商品链接”；价格不同的候选在计划编辑窗口人工选择。
  5. 点击发布已勾选项。中断后保留已完成状态，可续发未完成项。
注意事项：当前内部版本已关闭新手指引入口。本段仅保留为开发参考。
