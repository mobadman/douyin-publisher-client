新手指引与工作原理

按下面清单准备一次，日常使用只需选择日期、复核计划和开始发布。

软件如何工作

抖音批量发布助手分别保存飞书、测试账号和发布账号的本地 Chrome 登录环境。它从飞书表格复制只读数据，逐个下载当天附件，再按产品型号匹配本地封面、文案和 Tag。计划经人工确认后，脚本在抖音创作者中心逐条上传并设置定时时间。整个流程不使用生成式 AI，也不写入飞书。

飞书表格需要准备什么

必需列

【素材链接】【产品类目】【产品型号】【发布时间】。表头文字需与设置一致。

可选列

【允许发布】存在时，只有填写“是、允许、可发布、发布、true、1、yes、√”的行会进入计划。

素材链接

使用飞书附件或可下载的 HTTPS 链接；登录账号必须拥有表格查看和附件下载权限。

发布时间

人工填写希望发布的日期。软件只拉取所选日期，具体时刻按排期规则自动生成。

本地素材库结构

本地素材库/
  封面库/产品型号/*.jpg
  文案库/产品型号.txt
  Tag库/产品型号.txt
  下载缓存/
  发布日志/

文案和 Tag 文件每行一个方案；Tag 用逗号分隔，不必写 #。产品型号必须与飞书单元格一致。

日常操作步骤

  1. 在主工作台保存飞书电子表格链接，打开专用 Chrome 登录飞书并检测。
  2. 打开“发布账号”，首次扫码后检测并人工核对账号。
  3. 选择发布日期，点击“拉取飞书并生成计划”。
  4. 逐行检查视频、品类、型号、时间、文案、Tag和封面；问题项全部解决后勾选授权。
  5. 点击批量发布，期间不要操作设备。完成提示出现后，到作品管理核对数量和定时时间。
  6. 确认无误后清空下载缓存；发布日志会保留。
注意事项：拉取飞书素材和发布视频期间，不要移动鼠标、敲击键盘、切换窗口或运行其他前台任务。遇到问题时等待流程停止并生成错误报告，再由人工接管。
